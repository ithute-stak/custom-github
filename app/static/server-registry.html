Registered VPS Servers

Review the VPS entries stored by Custom GitHub, spot broken SSH identity paths, and unregister stale test records. Unregistering here changes only the local control-plane database — it never deletes the remote VPS, Docker containers, images, volumes, files or services.

Registered—Local VPS records
SSH identity ready—Configured key exists locally
Needs attention—Missing key or incomplete config
Safe to unregister—No deployment targets or history
A missing SSH key means Custom GitHub cannot connect to that registration. If the record is only an old test entry, unregister it. If it represents a real VPS, edit/re-register it with the correct SSH identity instead of deleting it.
